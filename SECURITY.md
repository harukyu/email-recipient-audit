# Security reporting

Report suspected security issues privately to **hey@nakaryu.de**. Include the project/version, a minimal synthetic reproduction, and the expected impact. Never send captured customer messages, private policies, credentials, or review texts.

Version 0.1.x is an early developer preview; there is no support SLA. Use current Python patch versions. The tool runs locally and does not make network requests or alter live websites. A report describes only the supported checks and is not a security certification.
