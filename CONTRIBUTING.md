# Contributing

Small, focused contributions are welcome. Describe the problem and use only synthetic fixtures. Follow the documented input/report schemas, preserve data minimization, and keep the runtime standard-library-only.

Do not include paid plugin implementations, customer exports, credentials, private logs, or external dependencies without discussion. Runtime changes should include appropriate regression coverage in the contribution. Current CI compiles syntax and builds the source archive; it does not provide a functional test suite.

Changes are accepted under the MIT license. By submitting a contribution, you confirm that you have the right to publish it.
